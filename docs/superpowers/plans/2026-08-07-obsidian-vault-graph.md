# Obsidian-First Graph-Connected Vault + Corpus Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a `tests/` tree open as a complete, graph-connected Obsidian vault — cases clustered by requirement and suite via generated hub notes — and migrate/repair the 2,789-case `onetest-ai-tm-Elitea` corpus into that shape (fix front-matter, renumber 169 duplicate IDs, add aliases).

**Architecture:** Two parts. **Part A** adds `_vault.py`, run by `build-index.sh` after the index, which generates `id`-less hub notes: requirement **proxy notes** that link *back* to their covering cases (`[[<ID>]]`, resolved via each case's `aliases`) with a GitHub-derived clickable URL, plus recursive `_index.md` MOCs. Case front-matter keeps `requirements:` **bare** — no wikilinks, no normalization; the requirement↔case edge is the proxy's backlink. **Part B** adds `_migrate.py`/`migrate-vault.sh` to repair the corpus: BOM fix, duplicate-ID reassignment (keep canonical, renumber the rest from `max+1`), and idempotent `aliases` insertion — dry-run by default.

**Tech Stack:** Python 3.9 (stdlib only — no PyYAML/pytest), Bash, Markdown/YAML front-matter, Obsidian 1.4+.

## Global Constraints

- **Stdlib only.** No new Python/Node deps. Front-matter parsing uses the existing `_tc.read_frontmatter`.
- **Python 3.9 compatible.**
- **Generated notes MUST omit `id:`** — the sole mechanism keeping them out of `index.json`/OQL/coverage (`_index.case()` returns `None` without an `id`).
- **Generated notes carry the marker** `generated by onetest-tms build-index — do not edit`; pruning only deletes marker-bearing files.
- **No wikilinks in case front-matter.** `requirements` stays bare `OWNER/REPO#N`. The only wikilinks in the vault are in generated proxy/MOC notes.
- **Requirement URL derivation:** `OWNER/REPO#N` → `https://github.com/OWNER/REPO/issues/N`. Bare `#N` uses `default_requirements_repo` from `.onetest/config.yml` if set, else no URL.
- **Migration is dry-run by default.** `_migrate.py`/`migrate-vault.sh` write only with `--apply`.
- **ID allocator:** new IDs continue from the corpus max (`ELITEA-2615` → first new `ELITEA-2616`), 4-digit zero-padded, keyed by the `ELITEA-` source key derived from existing IDs.
- **Canonical collision file** = the one with the lexicographically smallest repo-relative path (deterministic). All other files sharing that ID are reassigned.
- **Tests run via** `python3 onetest-tms/test/<file>.py` (each calls `unittest.main()`).

```python
#!/usr/bin/env python3
"""Generate Obsidian vault hub notes from the test-case index.

Emits id-less notes (invisible to the case tooling):
  tests/_meta/requirements/<safe>.md   requirement proxy; links back to covering cases
  tests/<folder>/_index.md             suite/module MOC (recursive)
  tests/_index.md                      vault root MOC

Requirement refs stay bare in cases (e.g. OWNER/REPO#N); the proxy note carries a
derived GitHub URL and lists [[<case-id>]] of every covering case.
"""
import argparse, json, os, re, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from _tc import read_frontmatter  # noqa: E402

GEN_MARK = "generated by onetest-tms build-index — do not edit"


def load_cases(index_path):
    return json.load(open(index_path, encoding="utf-8")).get("cases", [])


def safe_name(ref):
    return re.sub(r"[^A-Za-z0-9_.-]+", "-", ref).strip("-")


def derive_url(ref, default_repo):
    m = re.match(r"^([^/\s]+/[^#\s]+)#(\d+)$", ref)
    if m:
        return f"https://github.com/{m.group(1)}/issues/{m.group(2)}"
    if re.match(r"^#?\d+$", ref) and default_repo:
        return f"https://github.com/{default_repo}/issues/{ref.lstrip('#')}"
    return None


def collect_requirements(cases):
    covers = {}
    for c in cases:
        for ref in c.get("requirements", []):
            ref = ref.strip()
            if not ref:
                continue
            covers.setdefault(ref, [])
            if c["id"] not in covers[ref]:
                covers[ref].append(c["id"])
    return covers


def _req_note(ref, case_ids, url):
    lines = ["---", f'aliases: ["{ref}"]', "tags: [requirement]"]
    if url:
        lines.append(f"url: {url}")
    lines += ["---", "", f"# {ref}", ""]
    if url:
        lines += [f"External resource: <{url}>", ""]
    lines.append("## Covered by")
    lines += [f"- [[{cid}]]" for cid in sorted(case_ids)]
    lines += ["", f"<!-- {GEN_MARK} -->", ""]
    return "\n".join(lines)


def write_requirements(tests_dir, covers, default_repo=None):
    d = os.path.join(tests_dir, "_meta", "requirements")
    os.makedirs(d, exist_ok=True)
    written = []
    for ref in sorted(covers):
        p = os.path.join(d, f"{safe_name(ref)}.md")
        open(p, "w", encoding="utf-8").write(
            _req_note(ref, covers[ref], derive_url(ref, default_repo)))
        written.append(os.path.normpath(p))
    return written
```

```python
def moc_tree(tests_dir, cases):
    folders = {"": {"cases": [], "subdirs": set()}}
    for c in cases:
        rel = os.path.relpath(c["path"], tests_dir)
        folder = os.path.dirname(rel)
        parts = folder.split(os.sep) if folder else []
        for i in range(len(parts) + 1):
            folders.setdefault(os.sep.join(parts[:i]), {"cases": [], "subdirs": set()})
        for i in range(len(parts)):
            folders[os.sep.join(parts[:i])]["subdirs"].add(os.sep.join(parts[:i + 1]))
        folders[folder]["cases"].append((c["id"], c.get("title", "")))
    return folders


def _moc_note(folder, data):
    title = folder.split(os.sep)[-1] if folder else "Test Vault"
    lines = ["---", "tags: [moc]", "---", "", f"# {title}", ""]
    if data["subdirs"]:
        lines.append("## Suites")
        for child in sorted(data["subdirs"]):
            lines.append(f"- [[{child}/_index|{child.split(os.sep)[-1]}]]")
        lines.append("")
    if data["cases"]:
        lines.append("## Cases")
        for cid, ttl in sorted(data["cases"]):
            lines.append(f"- [[{cid}]] — {ttl}")
        lines.append("")
    lines += [f"<!-- {GEN_MARK} -->", ""]
    return "\n".join(lines)


def write_mocs(tests_dir, cases):
    written = []
    for folder, data in moc_tree(tests_dir, cases).items():
        p = os.path.join(tests_dir, folder, "_index.md")
        os.makedirs(os.path.dirname(p), exist_ok=True)
        open(p, "w", encoding="utf-8").write(_moc_note(folder, data))
        written.append(os.path.normpath(p))
    return written
```

Note: MOC subtree links are **path-qualified** (`[[alita-sdk/jira/_index|jira]]`) because every `_index` shares a basename; Obsidian resolves path-qualified links and `|name` gives a clean label.

```python
def _has_mark(path):
    try:
        return GEN_MARK in open(path, encoding="utf-8").read()
    except OSError:
        return False


def _is_generated(name, path):
    req_dir = os.sep + os.path.join("_meta", "requirements") + os.sep
    return name == "_index.md" or req_dir in (os.sep + path + os.sep)


def prune(tests_dir, keep):
    keep = {os.path.normpath(p) for p in keep}
    removed = []
    for root, _, files in os.walk(tests_dir):
        for f in files:
            p = os.path.normpath(os.path.join(root, f))
            if p in keep or not f.endswith(".md"):
                continue
            if _is_generated(f, p) and _has_mark(p):
                os.remove(p)
                removed.append(p)
    return removed


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--dir", default="tests")
    ap.add_argument("--index", default="index.json")
    ap.add_argument("--default-repo", default=None)
    a = ap.parse_args()
    cases = load_cases(a.index)
    reqs = write_requirements(a.dir, collect_requirements(cases), a.default_repo)
    mocs = write_mocs(a.dir, cases)
    prune(a.dir, reqs + mocs)
    print(f"vault: {len(reqs)} requirement notes, {len(mocs)} MOC notes", file=sys.stderr)


if __name__ == "__main__":
    main()
```

```markdown
# Obsidian vault

A `tests/` tree opens directly as an Obsidian vault. Cases keep machine-readable
front-matter; `build-index` generates hub notes so the Graph and Backlinks views
connect every case to its requirements and suites.

See also: [Test-case format](test-case-format.md) · [Configuration](configuration.md).

## Node types

| Node | File | Generated? |
| --- | --- | --- |
| Test case | `tests/<suite>/<sub>/<ID>_<slug>.md` | no |
| Requirement proxy | `tests/_meta/requirements/<safe>.md` | yes |
| Suite/module MOC | `tests/<folder>/_index.md` (recursive) | yes |
| Vault root MOC | `tests/_index.md` | yes |
| Tag hubs | native Obsidian tags from `tags:` (nested via `/`) | — |

Generated notes **omit `id:`**, so the index, OQL, and coverage ignore them. They carry
a `generated by onetest-tms build-index` marker and are rewritten (stale ones pruned) on
every `build-index` run — never hand-edit them.

## How the graph connects (proxy→case)

Cases contain **no wikilinks**. The requirement↔case edge is drawn by the generated
**proxy note linking back** to each covering case as `[[<ID>]]` (resolved via the case's
`aliases: [<ID>]`). Obsidian graph edges are undirected, so opening a case shows its
requirements in the Backlinks pane and clusters it with sibling cases on the same
requirement. MOC notes link down the folder tree the same way.

## Requirement URLs

Requirement refs stay **bare** in `requirements:` (e.g. `OWNER/REPO#N`). The proxy note
derives a clickable GitHub URL: `OWNER/REPO#N` → `https://github.com/OWNER/REPO/issues/N`.
A bare issue number uses `default_requirements_repo` from `.onetest/config.yml` when set.

## External links (reachable, not graphed)

Automation/doc URLs are pure-URL front-matter properties (`automation_pr`,
`automation_url`, `doc_url`) — clickable in the Properties panel, no graph node.

## Regenerating

`bash onetest-tms/scripts/build-index.sh --dir tests --out index.json` (or the MCP
`build_index` tool) rebuilds `index.json` and regenerates all hub notes.
```

```python
#!/usr/bin/env python3
"""Repair a test-case corpus for the Obsidian vault (dry-run unless --apply).

Fixes: BOM/leading-blank before front-matter; reassigns duplicate IDs
(keep canonical, renumber the rest); inserts `aliases: [<ID>]`.
"""
import argparse, os, re, sys
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
from _tc import read_frontmatter  # noqa: E402


def needs_fm_fix(text):
    if text.startswith("﻿"):
        return True
    i = 0
    lines = text.splitlines()
    while i < len(lines) and lines[i].strip() == "":
        i += 1
    return i > 0 and i < len(lines) and lines[i].strip() == "---"


def fix_fm(text):
    if text.startswith("﻿"):
        text = text[1:]
    lines = text.splitlines(keepends=True)
    while lines and lines[0].strip() == "":
        lines.pop(0)
    return "".join(lines)
```

```python
ID_RE = re.compile(r"^([A-Za-z][A-Za-z0-9]*)-(\d+)$")


def scan(tests_dir):
    recs = []
    for root, _, files in os.walk(tests_dir):
        for f in sorted(files):
            if not f.endswith(".md") or f == "README.md":
                continue
            p = os.path.join(root, f)
            fm, _b = read_frontmatter(p)
            cid = fm.get("id")
            if not isinstance(cid, str) or not ID_RE.match(cid):
                continue
            recs.append({"id": cid, "path": p, "seq": int(ID_RE.match(cid).group(2))})
    return recs


def max_seq(records):
    return max((r["seq"] for r in records), default=0)


def _key(cid):
    return ID_RE.match(cid).group(1)


def plan_reassign(records):
    by_id = {}
    for r in records:
        by_id.setdefault(r["id"], []).append(r)
    nxt = max_seq(records) + 1
    plan = []
    for cid, group in sorted(by_id.items()):
        if len(group) < 2:
            continue
        # canonical = smallest path; renumber the rest
        for r in sorted(group, key=lambda x: x["path"])[1:]:
            new_id = f"{_key(cid)}-{nxt:04d}"
            nxt += 1
            slug = os.path.basename(r["path"]).split("_", 1)[1] if "_" in os.path.basename(r["path"]) else os.path.basename(r["path"])
            new_path = os.path.join(os.path.dirname(r["path"]), f"{new_id}_{slug}")
            plan.append({"old_id": cid, "new_id": new_id, "path": r["path"], "new_path": new_path})
    return plan


def apply_reassign(item):
    text = open(item["path"], encoding="utf-8").read()
    text = re.sub(rf"(?m)^id:\s*{re.escape(item['old_id'])}\s*$", f"id: {item['new_id']}", text)
    text = re.sub(rf"(?m)^duplicate_of:\s*{re.escape(item['old_id'])}\s*$",
                  f"duplicate_of: {item['new_id']}", text)
    open(item["new_path"], "w", encoding="utf-8").write(text)
    if os.path.normpath(item["new_path"]) != os.path.normpath(item["path"]):
        os.remove(item["path"])
```

```python
def add_alias(path):
    lines = open(path, encoding="utf-8").read().splitlines(keepends=True)
    if not lines or lines[0].strip() != "---":
        return False
    end = next((i for i in range(1, len(lines)) if lines[i].strip() == "---"), None)
    if end is None:
        return False
    fm = lines[1:end]
    if any(re.match(r"^\s*aliases:", ln) for ln in fm):
        return False
    idx = next((i for i, ln in enumerate(fm) if re.match(r"^id:\s*(\S+)", ln)), None)
    if idx is None:
        return False
    cid = re.match(r"^id:\s*(\S+)", fm[idx]).group(1)
    fm.insert(idx + 1, f"aliases: [{cid}]\n")
    new = lines[:1] + fm + lines[end:]
    open(path, "w", encoding="utf-8").write("".join(new))
    return True


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--dir", default="tests")
    ap.add_argument("--apply", action="store_true")
    a = ap.parse_args()

    # 1) FM fix
    fm_fixes = []
    for root, _, files in os.walk(a.dir):
        for f in files:
            if f.endswith(".md") and f != "README.md":
                p = os.path.join(root, f)
                t = open(p, encoding="utf-8").read()
                if needs_fm_fix(t):
                    fm_fixes.append(p)
                    if a.apply:
                        open(p, "w", encoding="utf-8").write(fix_fm(t))

    # 2) reassign duplicate IDs
    plan = plan_reassign(scan(a.dir))
    if a.apply:
        for it in plan:
            apply_reassign(it)

    # 3) aliases (after reassignment so IDs are unique)
    alias_added = 0
    for r in scan(a.dir):
        if a.apply and add_alias(r["path"]):
            alias_added += 1

    mode = "APPLIED" if a.apply else "DRY-RUN"
    print(f"[{mode}] fm-fix: {len(fm_fixes)} files")
    print(f"[{mode}] reassign: {len(plan)} files (old->new):")
    for it in plan:
        print(f"    {it['old_id']} -> {it['new_id']}  {it['new_path']}")
    print(f"[{mode}] aliases added: {alias_added}" if a.apply
          else f"[{mode}] aliases: would add to cases missing one")


if __name__ == "__main__":
    main()
```

```bash
#!/usr/bin/env bash
# migrate-vault — repair a corpus for the Obsidian vault, then build the vault.
# Usage: migrate-vault.sh --dir tests [--apply] [--default-repo OWNER/REPO]
set -euo pipefail
HERE="$(cd "$(dirname "$0")" && pwd)"
DIR="tests"; APPLY=""; REPO=""
while [ $# -gt 0 ]; do case "$1" in
  --dir) DIR="$2"; shift 2;; --apply) APPLY="--apply"; shift;;
  --default-repo) REPO="$2"; shift 2;; *) echo "unknown: $1" >&2; exit 2;;
esac; done
python3 "$HERE/_migrate.py" --dir "$DIR" $APPLY
if [ -n "$APPLY" ]; then
  python3 "$HERE/_index.py" --dir "$DIR" --out index.json
  python3 "$HERE/_vault.py" --dir "$DIR" --index index.json ${REPO:+--default-repo "$REPO"}
  echo "✓ migrated + vault built"
else
  echo "(dry-run — re-run with --apply to write, then build-index)"
fi
```
