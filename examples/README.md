# Examples

Copy-paste starting points.

- [`_suite.yml`](_suite.yml) — a **dynamic suite**: drop into a folder under `tests/` to populate it
  from an OQL query instead of listing cases. See
  [authoring guide](../docs/guides/authoring-test-cases.md).
- [`sample-junit.xml`](sample-junit.xml) — a small JUnit report to try the automated-results flow
  (`ingest_results` → `correlate_results`). See
  [automated results](../docs/guides/automated-results.md).

For the shapes of generated reports and JSON artifacts, see
[report & artifact formats](../docs/reference/report-format.md).
